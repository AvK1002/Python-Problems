## 🧪 How to Use

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/python-sql-problems.git
   cd python-sql-problems
   ```

2. For Python problems, run:

   ```bash
   python3 python_problems/example_script.py
   ```

3. For SQL problems:

   * Use  **pgAdmin**, or **SQL** to run the `.sql` scripts on your test database.
